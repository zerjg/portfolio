# Портфолио — Игорь Пономарёв

Личный сайт-портфолио дизайнера.

🌐 **Живая версия:** https://zerjg.github.io/portfolio/

## Структура

- `index.html` — весь сайт (разметка + стили в одном файле)
- `project.html` — галерея проекта с лайтбоксом, например `?p=kord`
- `assets/` — изображения для карточек и галерей. Снимки внутренних интерфейсов хранятся в `assets/platforms/`.
- `dj/` — визитная карточка DJ ZERJG с историей жанров, самостоятельная страница. Шрифты лежат в `assets/fonts/dj/`, кадры для галереи в `assets/dj/` (сняты при окне 1440 × 810).
- `shop/` — интернет-магазин «Телефон Телефоныч»: главная, каталог, карточка товара и мобильная главная. Страницы статические, только карточка товара дорисовывается скриптом `shop/dcmini.js` из шаблонов в `shop/dc/`, чтобы работали переключатели цвета и фото. Фото устройств лежат в `assets/shop/img/`, шрифты в `assets/fonts/shop/`, кадры для галереи в `assets/shop/` (сняты при окне 1440 × 810).
- `school/` — концепт сайта Школы английского языка Дмитрия Никитина, самостоятельная страница. Фото школы лежат в `assets/school/img/`, шрифт Onest в `assets/fonts/school/`, кадры для галереи в `assets/school/` (сняты при окне 1440 × 810).
- `art/` — сайт апсайкл-бренда одежды ART: главная с выбором конкретного экземпляра куртки, паспортом вещи и шагами производства. Выбор экземпляра и ракурсов работает на небольшом скрипте внутри страницы. Фото лежат в `assets/art/img/`, шрифты в `assets/fonts/art/` (Golos Text берётся из общих `assets/fonts/`), кадры для галереи в `assets/art/` (сняты при окне 1440 × 810).
- `most/` — лендинг музыкальной студии МОСТ (Ярославль): уроки, звукозапись VOSTORG records, цены и подарочные сертификаты. Самостоятельная страница, табы и карусель работают на небольшом скрипте внутри. Использует шрифты Geologica из `assets/fonts/dj/` и Onest из `assets/fonts/shop/`. Фото и логотип лежат в `assets/most/img/`, кадры для галереи в `assets/most/` (сняты при окне 1440 × 810).
- `assets/webdev/` — кадры учебной платформы WebDev в тёмной и светлой теме (1440 × 810), проект показан только галереей.
- `prototypes/` — концепт «Цифры» на демонстрационных данных. Экраны доступны по `?p=cifra&screen=1…6`. Данные экранов находятся в `prototypes/screens.js`, снимки сделаны при размере окна 1440 × 810.

Проект «Цифра» скрыт, но остаётся в коде. Карточка на главной помечена атрибутом `hidden`, а у записи `cifra` в `project.html` стоит флаг `hidden: true`. Чтобы вернуть проект на сайт, уберите и то, и другое.

## Как редактировать

1. Откройте `index.html`
2. Замените карточки-заготовки в секции «Избранные работы» своими проектами
3. Обновите тексты в секциях «Обо мне» и «Навыки»
4. Закоммитьте изменения — GitHub Pages обновится автоматически

## Публикация

Сайт публикуется через GitHub Pages из ветки `main` (корень репозитория).
